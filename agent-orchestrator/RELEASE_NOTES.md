## 本地协作工作台

- 标准库 HTTP/SSE、SQLite 与原生 JavaScript 提供任务房间、运行证据、审批、暂停/继续、取消和重跑。
- 全历史关键词/项目/状态组合筛选及稳定游标分页；历史摘要不写投影游标、不加载报告正文，源状态变化使缓存失效。

- 指令准入与终态发布串行化；worker 最后检查点后的已准入暂停在交接处补处理，不重跑已完成 attempt，也不重复记账。
- 有限双角色会诊沿用固定快照和独立预算；建议不自动变成代码或通过结论。

## 实测边界

仅支持本地单用户工作台。worktree、路径白名单和快照不是操作系统沙箱；只登记可信配置。关闭页面或工作台服务不等于取消独立任务。暂停在检查点生效，仍受原墙钟期限限制。
